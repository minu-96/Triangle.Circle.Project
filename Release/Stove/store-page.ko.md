# 스토브 상품 페이지 초안 — 삼각원

> 개발 상태를 읽고 만든 등록용 카피와 그래픽 시안입니다. 가격, 출시일, 공식 영문 표기, 이용등급은 확정값이 없어 입력란을 비워 두었습니다. Studio의 등록 화면에서 실제 노출 규격과 입력 길이를 확인하고 적용합니다.

## 기본 정보 초안

- **상품명:** 삼각원
- **한 줄 소개:** 같은 도형은 구역마다 두 개까지. 아홉 칸씩 천천히 채워보는 가벼운 퍼즐.
- **장르 제안:** 퍼즐 · 캐주얼 · 논리
- **플레이 인원:** 1인
- **주요 특징:** 81개 스테이지 · 4개 챕터 · 클래식 난이도 3종 · 엔드리스 · 힌트 · 기기 저장
- **지원 언어:** 한국어 (출시 빌드로 언어 지원을 확인한 뒤 등록)
- **플랫폼·운영체제:** PC 상품 유형과 빌드 요구사항을 Studio 등록 단계에서 확정
- **가격·출시일·이용등급:** 추후 결정

## 짧은 소개

아홉 칸씩 채워보는 도형 퍼즐. 행·열·3×3 블록마다 같은 도형을 두 개까지만 놓으며, 81개 스테이지와 엔드리스까지 한 칸씩 나아가세요.

## 상세 소개

익숙한 9×9 퍼즐을 다섯 가지 알록달록한 도형으로 풀어보세요. 가로 한 줄, 세로 한 줄, 굵은 선으로 나뉜 3×3 블록 안에는 같은 도형을 최대 두 개까지만 놓을 수 있어요. 빈칸을 모두 채우고 규칙까지 지키면 완성입니다. 처음 놓인 단서는 고정되어 있고, 원하는 칸을 골라 도형을 하나씩 놓아보세요.

**내 리듬대로 즐기는 클래식**  
빈칸 15개, 35개, 55개 중 하나를 골라보세요. 세 난이도 모두 무작위로 만든 보드에서 시작합니다.

**다른 느낌의 네 챕터**  
총 81단계에서 빈칸 수가 늘어나고 배치 전략이 바뀝니다. 입문은 무작위, 집중은 블록 중앙, 균형은 각 블록에 고르게, 종합은 세 전략을 섞습니다. 다음 단계는 하나씩 열립니다.

**완성 뒤에도 이어지는 엔드리스**  
마지막 스테이지를 마치면 새 퍼즐을 계속 이어서 즐길 수 있어요. 플레이 기록은 이 기기에 저장됩니다.

원하는 칸에 맞는 힌트를 받아보고, 효과음과 작은 움직임을 편하게 조절하세요. 잠깐씩 쉬어 가며 한 칸씩 채우는 1인 도형 퍼즐입니다.

## 캡슐·이미지의 카피

- 메인 카피: **작은 도형, 즐거운 생각**
- 서브 카피: **한 칸씩 채우는 9×9 도형 퍼즐**
- 스펙 라인: **81개 스테이지 · 4개 챕터 · 클래식 · 엔드리스**

## 기능 태그 제안

퍼즐, 캐주얼, 논리, 1인, 오프라인, 도형, 스테이지 진행, 편안한 플레이.  
태그 입력란이 제공되는 범위에서 상품 내용과 맞는 표현을 골라 사용합니다. 등재 여부나 추천 노출을 보장하는 키워드가 아닙니다.

## 등록 전 채워야 하는 항목

1. Studio 입점 승인과 Game ID 발급, 상품 표시 필드 및 실제 이미지 슬롯 규격.
2. 판매 유형·가격·출시일·운영 국가·빌드 OS 및 최소 사양.
3. 최종 출시 빌드의 한국어 지원 범위, 언어별 페이지 노출 설정과 이용등급.
4. PC 상품의 SDK·계정 연결 요구사항을 계약 및 개발사 안내에서 확인하고 Sandbox 빌드·검수 일정을 확정.
5. 새 Unity 화면을 실행해 실제 상품 스크린샷을 촬영합니다. `screen-designs/`의 콘셉트 시안이나 `prototype-gameplay-reference-1024x1536.png`는 출시 빌드 캡처가 아니므로 실제 스크린샷 칸에 넣지 않습니다.

스토브 공개 가이드는 개발사 등록, 기본 상품 정보, 표시 설정, Game ID, Sandbox 업로드·검수와 라이브 노출 순서를 안내합니다.
