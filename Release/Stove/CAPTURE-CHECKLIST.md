# 최종 스토어 스크린샷 촬영 순서

`Samgakwon.unity` 또는 승인된 출시 빌드를 16:9/16:10 PC 해상도에서 촬영하고, 플레이 화면 안의 메모/팝업은 실제 사용 가능한 출시 빌드 상태로 맞춥니다.

1. 첫 플레이 — 9×9 격자와 다섯 도형 선택이 함께 보이는 장면.
2. 클래식 — 15/35/55 빈칸 난이도 선택.
3. 챕터 — 열린 단계와 잠긴 단계가 구분되는 스테이지 선택.
4. 플레이 — 도형을 놓은 보드와 선택된 행·열·블록 하이라이트.
5. 완성 — 게임 안의 실제 완성/신기록 팝업.
6. 엔드리스 — 보너스 퍼즐과 현재 누적 클리어 수.

화면을 자르지 않은 원본과 STOVE Studio 슬롯 규격별 파생본을 같이 보관합니다. 현재 가이드 묶음의 `screen-designs/` 파일은 최종 게임플레이 캡처가 아닙니다.
