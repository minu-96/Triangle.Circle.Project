# 삼각원 브랜드 가이드

## 시각 방향

가볍고 밝은 퍼즐. 종이처럼 포근한 배경 위에서 색과 모양이 먼저 읽히게 합니다. 그림자와 장식을 줄이고, 짧은 카피와 둥근 면으로 편안한 리듬을 만듭니다.

## 색상

| 이름 | HEX | 사용 |
| --- | --- | --- |
| 크림 | `#FFFBF3` | 페이지, 앱 아이콘 바탕 |
| 짙은 회색 | `#484B57` | 제목, 본문 |
| 민트 | `#08AAA5` | 선택, 버튼, 강조 |
| 옅은 민트 | `#E7F7F2` | 선택 행, 칩, 보조 면 |
| 보드 선 | `#D2C8B9` | 3×3 구역과 프레임 |
| 삼각형 | `#FF8875` | 도형 토큰 |
| 원 | `#44BDB5` | 도형 토큰 |
| 사각형 | `#FFC342` | 도형 토큰 |
| 마름모 | `#B286DE` | 도형 토큰 |
| 오각형 | `#59ADF0` | 도형 토큰 |

## 글꼴과 로고

한글은 Nanum Gothic으로 표시합니다. PNG의 타이포그래피는 프로젝트에 포함된 Nanum Gothic으로 렌더링합니다. SVG 텍스트를 수정한다면 Nanum Gothic을 선택하세요.

투명 워드마크는 `source/wordmark-transparent.svg` 또는 `assets/wordmark-transparent-1500x360.png`, 타일 배경이 있는 앱 아이콘은 `assets/app-icon-512.png` / `app-icon-1024.png`를 사용합니다. 심볼과 게임 이름은 각각 있으므로 아주 작은 아이콘은 아이콘만 사용합니다.

가로 워드마크는 폭 기준 약 1/2 높이의 여백을 둡니다. 상품 그림에는 로고를 한 번만 크게 두고, 격자와 서로 경쟁하는 보조 문구를 늘리지 않습니다. 다섯 모양의 색 대응은 일관되게 유지합니다.

## 문구

- 대표: **작은 도형, 즐거운 생각**
- 보조: **한 칸씩 채우는 9×9 도형 퍼즐**
- 기능: **81개 스테이지 · 4개 챕터 · 클래식 · 엔드리스**

짧고 편안한 한국어 문장을 사용하고 점수·순위·온라인 기능을 약속하지 않습니다. 현재 범위에서 확인되지 않은 가격·출시일·컨트롤러·지원 언어를 이미지에 새기지 않습니다.

## 권장 이미지 여백

표기된 크기는 제작 원본의 크기입니다. Studio에서 입력 항목을 열어 요구 크기와 비율을 확인하기 전까지 공식 규격으로 간주하지 않습니다. 가로형 키아트의 핵심 제목과 퍼즐 격자는 중앙 약 80% 영역에 놓고 가장자리 장식은 크롭되어도 의미가 유지되도록 합니다. Studio가 맞지 않는 비율을 요구하면 함께 제공한 Python 원본 제작 스크립트에서 캔버스 크기를 조정하세요.
